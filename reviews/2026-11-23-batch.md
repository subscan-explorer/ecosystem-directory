Mappings: Talisman hydradx -> hydration; polkadot-asset-hub -> assethub-polkadot;
kusama-asset-hub -> assethub-kusama; bifrost-polkadot -> bifrost (existing Subscan
slug). Nova's current display name Polkadot is the Hub (genesis 68d56f...), whereas
Polkadot Relay is genesis 91b171.... Kusama Hub and Relay are also distinct.
Ethereum is included as an actual bridge/wallet/staking destination; this does not
imply that Subscan operates an Ethereum explorer. Bifrost Kusama is a separate
external network view, not a claim that a dedicated Subscan explorer exists.

Do not infer supported chains from token names or ecosystem membership. Listing a
wallet on a chain does not assert every task is available there; wallet entries
only expose the wallet task. The listed networks are a reviewed subset, not an
exhaustive product support matrix. Developer resource association denotes covered
network documentation, not deployment.
